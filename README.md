# ESP32 Industrial I/O Controller

A custom 4-layer ESP32-based industrial I/O controller designed in KiCad.

## Features

- ESP32-WROOM-32E
- 24 V input
- 0–10 V analog input
- 4–20 mA analog input
- RS485 communication
- USB-C programming/debugging
- 24 V relay output
- 5 V buck converter
- 3.3 V regulation
- 4-layer PCB
- Dedicated GND plane
